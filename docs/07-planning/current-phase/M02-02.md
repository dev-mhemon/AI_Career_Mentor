  - Backend synthetic integration test suite:
    - `backend/src/auth/phone-identity.integration.spec.ts` (24 synthetic integration tests) covering:
      - Section 1: EP-A03 (`POST /auth/verify-phone`) — phone verification, GoTrue user update, local `users.phone` and `users.verified_contact = true` update, rate-limit / lockout propagation, and fail-closed 503 `SERVICE_UNAVAILABLE` when SMS provider is disabled.
      - Section 2: EP-A10 (`POST /auth/oauth/session`) — OAuth session exchange, Facebook unverified bootstrap (`verified_contact = false`), `verified_contact_required: true` flag, and `next_step: 'add_verified_contact'`.
      - Section 3: EP-A11 (`POST /auth/identities/link`) — social identity linking (Google / Facebook), `403 VERIFIED_CONTACT_REQUIRED` guard on unverified accounts, `409 IDENTITY_LINK_CONFLICT` on provider collisions, and `user_auth_providers` insertion on success.
      - Section 4: EP-A12 (`POST /auth/contact`) — secondary contact addition for authenticated users, uniqueness check, unverified `user_auth_providers` insertion, email challenge dispatch (`RegistrationPendingDTO`), phone 503 fail-closed while SMS disabled, and `409 ALREADY_VERIFIED` rejection when contact is already verified.
      - Section 5: Cross-cutting & Envelope Integrity — single-envelope wrapping verification through `ApiExceptionFilter` (`success: false`, `error: { code, message, requestId, details, retryAfterSeconds }`), zero PII in error messages and logs, and `23505` unique violation translation to 409 conflict.
  - Frontend Screen 22 (`/settings`) Auth settings:

    - `frontend/src/components/settings/add-contact-form.tsx`: Client component supporting email and phone contact addition with R18 draft persistence (`context: 'secondary_contact'`), server action state integration with `[state]` dependency, draft cleanup on rejection, and redirect to `/verify`.

    - `frontend/src/app/settings/page.tsx`: Server component integrating `IdentityLinkingCards`, `VerifiedContactPrompt`, and `AddContactForm`, awaiting dynamic `searchParams` for linked/error/prompt banners, with auth session verification.
