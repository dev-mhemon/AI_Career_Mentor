    - `PostgresJobQueueConsumer`: unwraps TypeORM `[rows, rowCount]` tuples on all `UPDATE ... RETURNING` writes; claims batches via `FOR UPDATE SKIP LOCKED` on `idx_ai_requests_queue` and commits `queued -> preparing` BEFORE invoking external handlers; runs bounded-batch execution via `Promise.allSettled` so `pollingInFlight` never clears before sibling jobs settle; runs a 30s fenced heartbeat (`(id, locked_by, attempt_count)` bounded by `maxAgeSeconds`) that aborts `AbortSignal` on fence loss or age expiry; performs deadlock-safe commit-gate locking (unlocked `ai_requests` lookup -> `public.users FOR SHARE OF u` FIRST -> `public.ai_requests FOR UPDATE` SECOND) requiring `verifyExpectedRefs` on ref-bearing kinds, unconditionally rechecking `within_deadline` + live owner/feature access before `persistArtifact`, committing domain artifact + `public.ai_generations` + `status = 'succeeded'` + `input_payload = NULL` atomically, logging only `job.id` + fixed failure codes (never raw error messages), and using two-step `preparing -> failed` then `failed -> queued` with zero-row terminal purge.
    - `JobReaperService`: implements `OnApplicationBootstrap` (`start()` in non-test runtime) + `OnModuleDestroy`; unwraps TypeORM `[rows, rowCount]` tuples across all `UPDATE ... RETURNING` writes; sweeps stalled or over-age async `'preparing'` jobs using strict two-step `preparing -> failed` then separate `failed -> queued` (never `preparing -> queued`, preserving `private.validate_ai_request_status()` `23514`), terminalizes over-age unclaimed `'queued'` jobs (`queued -> failed`, explicitly permitted by `015_functions.sql:106`), terminalizes abandoned synchronous (`is_async = false, status = 'preparing'`) quota reservations directly (`preparing -> failed`, `retryable = false`, never requeued), and samples `randomFn()` once per `computeRetryBackoffSeconds` call.
