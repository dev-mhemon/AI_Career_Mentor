### Post-Audit Live Fixes & Evidence (2026-11-11)

1. TextBee Env Loading:
   - Root Cause: `scripts/foundation/local.mjs` was not parsing `backend/.env`, causing `.local/foundation/backend.json` and backend execution to run without `TEXTBEE_API_KEY` and fallback to Mailpit.
   - Fix: Added `parseEnvFile` helper to `scripts/foundation/local.mjs` loading `backend/.env` into `.local/foundation/backend.json` and process env; updated `app.module.ts` `envFilePath` to include `backend/.env`. Updated `.local/foundation/backend.json` with live TextBee credentials.

2. Phone OTP Verification 502/503 "Service temporarily unavailable":
   - Root Cause:
     a. `cleanupSyntheticPhoneEmail` was called inside `this.database.transaction` which defaulted to `SET LOCAL ROLE service_role`. In PostgreSQL, `service_role` lacks UPDATE permissions on `auth.users`, throwing `permission denied for table users` and rolling back the transaction.
     b. In `mintAndApproveSession`, `/auth/v1/verify` was called with hardcoded `type: 'magiclink'`, whereas GoTrue returns `verification_type: 'signup'` for newly provisioned identities, failing with HTTP 403 `otp_expired`.
   - Fix:
     a. Passed `useServiceRole = false` (`channel !== 'phone'`) in `this.database.transaction` so operations run as superuser `postgres` with full DML rights over `auth.users`.
     b. Dynamic `type: linkData?.verification_type || linkData?.properties?.verification_type || 'magiclink'` in `mintAndApproveSession`.
