  - `TextBeeSmsProvider`: Implement unified SMS provider supporting live TextBee REST dispatch (`POST /gateway/send-sms` or `/gateway/devices/:deviceId/send-sms` with `redirect: 'error'`, `x-api-key` header, JSON `{ recipients: [phone], message }`), local dev Mailpit fallback (`${sanitizedPhone}@sms.local` via `POST /api/v1/send` with `redirect: 'error'`) in non-production when `TEXTBEE_API_KEY` is omitted, and fail-closed `503 SERVICE_UNAVAILABLE` in production.

    - `EP-A01` (`POST /api/v1/auth/register` with `channel: 'phone'`): Option 2B GoTrue Admin pending user creation with phone, unverified `public.users` and `public.user_auth_providers` persistence, 6-digit Redis OTP generation, and SMS OTP dispatch.
    - `EP-A02` (`POST /api/v1/auth/verify-otp` with `channel: 'phone'`): Verify Redis OTP, confirm GoTrue user, mark `verified_contact = true` in `public.users` and `user_auth_providers`, ensure user profiles/preferences exist, approve session in `private.approved_auth_sessions`, and return session tokens.
    - `EP-A04` (`POST /api/v1/auth/resend-otp` with `channel: 'phone'`): Abuse control rate limiting and OTP re-dispatch via `TextBeeSmsProvider`.
    - `EP-A05` (`POST /api/v1/auth/login` with `channel: 'phone'`): Phone + password authentication, session approval, and token issuance.
    - `EP-A08` / `EP-A09`: Password recovery OTP dispatch and reset with phone channel support.
    - `EP-A12`: Add secondary phone contact with SMS challenge dispatch.
  - Frontend: Support phone registration tab switching, draft preservation, unverified phone login redirect to `/verify?channel=phone`, and phone OTP resend in `register-form.tsx` and `actions.ts`.
