# Terminology ownership

Canonical product terms are in [C01 §61](../01-product/PRD.md); SQL enums in [C06 §5](../04-database/DMS.md); HTTP DTOs in [C05 §15](../05-api/API-Specification.md). This index does not redefine them.

Evidence vocabulary: Specified = contract exists; Implemented = named source/commit exists; Executed = named command/environment/result exists; Accepted = explicit reviewer/owner gate recorded. Historical execution is not live service health. R32 remains in_progress/partially_executed; R33 remains optional/deferred.
