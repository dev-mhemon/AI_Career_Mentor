| [H-IDEM replay & R14 epoch](../../backend/src/jobs/services/idempotency.service.ts), [validation](../../backend/src/config.ts); [public template](../../backend/.env.example) | IDEMPOTENCY_REDIS_URL, IDEMPOTENCY_REDIS_EPOCH, IDEMPOTENCY_TTL_SECONDS=86400, IDEMPOTENCY_REDIS_TIMEOUT_MS=1000, IDEMPOTENCY_REDIS_RETRY_SECONDS=5, IDEMPOTENCY_BOOTSTRAP_ON_INIT | Optional server-only Redis replay configuration (`M04-01` / `R14`). Clean initial deployment uses one-time `IDEMPOTENCY_BOOTSTRAP_ON_INIT=true` (so `onModuleInit()` invokes `bootstrapInitialEpoch()` using `SET idempotency:epoch <epoch> NX`) or explicit pre-traffic invocation of `app.get(IdempotencyService).bootstrapInitialEpoch()` before opening ingress; normal serving instances run with `IDEMPOTENCY_BOOTSTRAP_ON_INIT` unset/`false` (`execute()` never self-seeds). Mandatory pre-restore fence: before making any restored Redis snapshot/RDB/AOF reachable, suspend ingress and stop/roll instances to a rotated `IDEMPOTENCY_REDIS_EPOCH = E_new` (or delete `idempotency:epoch` in an isolated restore before exposing Redis). Before reconciling `public.ai_requests` or waiting out the recovery window, drain/stop all pre-loss in-flight `handler()` calls (or exceed the bounded request/statement timeout so all pre-loss handlers commit or roll back); then lift the fence with `acknowledgeEpoch(E_new)` only after durable reconciliation completes or the longest configured reservation lifetime (`IDEMPOTENCY_TTL_SECONDS`, default 24 hours / 86,400 seconds) elapses. |

The local helper generates private runtime configuration and ES256 keys; it supplies generated app configuration when launching the apps rather than trusting stale ignored .env values. Never copy status JSON, signing keys, runtime backend/frontend JSON or private logs into documentation or Git. The ignored .local/windows-tools.json can retain operator-specific nonsecret tool paths; do not commit its contents or machine-specific absolute paths. Global exports/settings are unnecessary.

Public anon/publishable keys are distinct from user access JWTs. Document variable names, scope and consumers, not credentials or real runtime values. POSIX mode requests in a helper do not constitute an audit of Windows ACLs. Use actual filesystem permissions and .gitignore; no universal AI-ignore enforcement is claimed.

Network dependencies described by the current tooling include GitHub Git/REST/artifacts, npm, official Supabase/Docker registries and Google Fonts build hosts. This is an inventory, not evidence that a network allowlist or proxy setting is enforced. Do not disable TLS, checksum, health or image checks.

M01-02 supplies the Auth Redis enabler and M04-01 adds the Redis `H-IDEM` idempotency (`IDEMPOTENCY_TTL_SECONDS`, default 24 hours / 86,400 seconds) and `R14` loss-epoch barrier above; AI provider keys and background worker queue configuration remain deferred to subsequent M04 slices and are not fabricated here.
